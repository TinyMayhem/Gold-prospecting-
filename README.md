# Gold Prospecting Solver V5

Android read-only companion for Last War Gold Prospecting.

## V5

V5 adds device calibration so screen detection and the placement overlay use the same saved geometry.

- Calibrate the 8x8 board from one screenshot.
- Calibrate LEFT / MIDDLE / RIGHT piece boxes.
- Exact detected piece shapes are highlighted over the target board cells.
- R/C coordinates remain visible under the corresponding pieces.
- Each coordinate card contains a miniature color preview of the piece the detector recognized.

The app does not tap, drag, or control Last War.

## Build

Push to GitHub and open Actions. The included workflow builds `GoldProspectingSolver.apk` and uploads it as `GoldProspectingSolver-APK`.
