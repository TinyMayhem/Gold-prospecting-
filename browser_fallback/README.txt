GOLD PROSPECTING SOLVER - ANDROID BROWSER VERSION

This version does not need Python or a computer once the file is on your phone.

HOW TO USE ON ANDROID
1. Copy index.html to your phone.
2. Open index.html in Chrome or Samsung Internet.
3. Set the gem totals shown in Last War.
4. Tap "Choose your Last War screenshot" and select the newest screenshot.
5. The solver automatically reads the board and three pieces, then draws numbered placements over the screenshot.
6. If a piece is detected incorrectly, open "Detection check / fix a piece", tap its cells to correct it, and press Re-solve.

IMPORTANT
- Take the screenshot after the three new pieces stop moving/animating.
- This is calibrated to the 709 x 1536-style screenshots used during development. Same aspect ratio/resolution families should work best.
- This is a read-only solver. It does not tap or drag anything in Last War.

NEXT STEP
